# 糖猫桌宠

糖猫桌宠是一只可爱有趣的 Windows 桌宠，使用 Electron 和原生 JavaScript 开发。

仓库提供源码、行为配置和素材清单，表情包由使用者自行准备。按清单放入 PNG 和 GIF 后，可以直接从源码运行，也可以在本地打包为双击启动的 EXE。

## 功能概览

- **表情与动作**：随机切换站立、工作、睡觉等日常状态；悬停会改变表情，单击播放普通动作，双击播放 GIF，动作配有气泡文案。
- **自主活动**：在当前显示器内迈步、跳跳或跑动，遇到边缘改变方向。
- **拖拽与投掷**：拖动糖猫调整位置，也可以拖到另一块屏幕；快速甩出后会飞行、反弹，最后显示落地表情。
- **鼠标玩耍**：开启一轮 90 秒的互动，糖猫会朝向、靠近和追逐鼠标，也会伸手或对绕圈作出疑惑反应。
- **性格与环境感知**：安静、默认、活泼三种性格控制活动频率；本地时间和系统空闲状态会影响睡觉、工作等动作的偏好。
- **桌面控制**：支持四档大小、暂停活动、鼠标穿透和托盘藏起／叫回；所在显示器出现全屏应用时自动隐藏，退出全屏后恢复。

## 开始使用

### 1. 安装依赖

在 Windows 10/11 x64 上准备 Node.js 22.12.0 或更高版本、Python 3.10 或更高版本。在 PowerShell 中获取源码并安装依赖：

```powershell
git clone https://github.com/WalnuTpz/touneko-desktop-pet.git
cd touneko-desktop-pet
python -m pip install -r requirements.txt
npm ci
```

### 2. 添加表情包素材

根据 `assets/catalog.json` 创建目录并放入文件：

| 清单字段 | 文件路径 | 当前数量 |
|---|---|---:|
| `staticAssets` | `assets/local/static/<id>.png` | 136 张 |
| `animatedAssets` | `assets/local/animated/<id>.gif` | 21 份 |

每个 ID 都要有对应文件，例如 `stand` 使用 `stand.png`，`movement-jump` 使用 `movement-jump.gif`。图片按清单中的日常、动作和移动用途匹配；角色透明背景用于轮廓命中和碰撞。

### 3. 运行桌宠

```powershell
npm start
```

命令会先生成运行时素材，再通过 Electron 打开桌宠。糖猫出现在主显示器右下角，系统托盘同时出现图标。这条路径直接使用本地源码和素材。

下次使用时在项目根目录执行同一命令。结束使用时，右键糖猫或托盘图标选择“退出”。

## 打包为本地程序

需要双击启动时，先确认素材显示与互动正常，从托盘退出桌宠，再执行：

```powershell
npm run dist
```

命令会执行检查、测试和打包，在 `release/` 中生成包含 Electron 与当前素材的便携版 EXE。运行成品时无需另行安装 Node.js 或 Python。替换素材后，先按开发指南核对显示尺寸与动画效果。
