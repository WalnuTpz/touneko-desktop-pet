# 录制桌宠演示

这份脚本安排现有功能的演示顺序。成片以清楚展示操作和反馈为目标，保留程序的随机结果；录制次数用于执行，画面使用简短功能字幕。

## 准备画面

在 Windows 桌面启动糖猫，使用 `100%` 大小，关闭鼠标穿透，恢复活动。首次启动镜头从右下角开始，其余主要镜头在屏幕中央拍摄。角色偏离构图较多时，等待当前投掷或落地反馈结束，再缓慢拖回中央；辅助归位可以剪短。

用字幕解释功能。本片展示表情、点击、移动、拖放、投掷、玩耍、大小和托盘设置；暂停、穿透与全屏自动隐藏留作独立操作演示。

## 启动、日常与点击

1. 完整退出已有糖猫后重新启动，保留右下角出场和一次完整开场白。
2. 缓慢拖到中央，完整展示倒立拖拽形象与正常放下。
3. 展示四次随机日常，每次移入、移出角色三次，观察悬停和恢复。组间通过低速小幅拖放开始新日常。
4. 演示三次独立单击，每次等待系统确认后，让动作与气泡显示约 1～2 秒。后一次点击可以接管前一个动作。
5. 演示三次双击，每个 GIF 显示约 1～2 秒，观察它直接接管前一个动作。

日常和悬停允许抽到重复结果。录制保留实际抽取，不为了指定表情重抽。

## 移动与投掷

通过右键“出去走走”演示三次移动，完整保留每次动画、行进和停止位置。类型、轴与方向使用实际随机结果，经过边缘时保留反弹和转向。每次结束后按需要低速归位。

接着演示两次投掷：选择一个斜向方向，快速拖动并松手，完整保留飞行、反弹、减速和落地表情。落地结束后再归位。两次方向可以相同。

## 鼠标玩耍

右键选择“和糖猫玩耍”，依次录制：

1. 在角色左右移动鼠标，展示朝向变化。
2. 把鼠标移远，展示靠近。
3. 在角色附近缓慢移动，展示拍鼠标。
4. 绕角色画圈，展示疑惑。
5. 等待一次追逐。
6. 玩耍期间单击，保留继续玩耍的画面。
7. 右键选择“停止玩耍”，结束会话。

字幕说明每轮最长 90 秒，本段使用菜单提前结束。

## 大小与托盘

依次切换 `75%`、`100%`、`125%`、`150%`，每档短暂停留，最后恢复 `100%`。使用相同背景作大小参照。

打开托盘，展示环境感知、三种性格、调整大小、藏起/叫回和退出。字幕说明“性格改变自动活动频率，环境感知调整动作偏好”，无需等待抽样呈现概率差异。

从角色右键选择“藏起来”，保留角色消失和托盘图标。再从托盘选择“叫糖猫回来”，保留回到显示器右下角的画面，随后低速拖回中央。

## 随机动作集锦与收尾

通过右键“随机动作”连续触发二十次，每个展示约 1 秒。第一次保留菜单操作，后续重复打开菜单的镜头可以剪短。保留静态和 GIF 的实际随机结果，最近五个动作过滤正常运行。

最后一个动作多停留约 2 秒。结束画面让糖猫留在中央，字幕为：

> 糖猫桌宠：一只可爱有趣、陪伴你的 Windows 桌宠

完成后检查镜头数量：四组日常与每组三次悬停、三次单击、三次双击、三次移动、一次完整普通拖放、两次投掷和二十次随机动作。录制媒体保存在本地工作目录。
