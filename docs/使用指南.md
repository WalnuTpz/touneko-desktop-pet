# 使用糖猫桌宠

本文从准备表情包开始，介绍如何在 Windows 上运行糖猫，以及怎样操作它的互动和托盘设置。

## 第一次运行

准备 Windows 10/11 x64、Node.js 22.12.0 或更高版本、Python 3.10 或更高版本。在 PowerShell 中获取源码并安装依赖：

```powershell
git clone https://github.com/WalnuTpz/touneko-desktop-pet.git
cd touneko-desktop-pet
python -m pip install -r requirements.txt
npm ci
```

后续命令均在包含 `package.json` 的项目根目录执行。`npm ci` 使用仓库锁定的依赖，包含运行桌宠所需的 Electron；Python 的 Pillow 库负责处理图片。

接着打开 `assets/catalog.json`，按清单中的 ID 准备表情包。ID 是图片的稳定名称，清单将它们分配给日常、悬停、动作和移动等用途。

| 清单列表 | 本地路径 | 示例 |
|---|---|---|
| `staticAssets` | `assets/local/static/<id>.png` | `stand.png` |
| `animatedAssets` | `assets/local/animated/<id>.gif` | `movement-jump.gif` |

1. 创建上表的两个本地目录。
2. 为每个声明的 ID 放入对应文件，当前共需 136 张 PNG、21 份 GIF。按用途选择内容，例如站立图用于日常，连续迈步姿势用于移动。
3. 使用有可见内容的透明背景图片。角色轮廓决定鼠标命中和碰撞范围；同一图片用于多个行为时，通过清单复用同一个 ID。
4. 在项目根目录执行：

```powershell
npm start
```

命令先校验源文件、生成运行素材，再启动窗口。终端显示“素材准备完成”后，糖猫出现在主显示器右下角，播放一次开场白，通知区域出现托盘图标。托盘图标被折叠时，展开通知区域即可找到。

平时也用这条命令启动。更换图片后，它会重新生成素材。结束使用时，右键角色或托盘图标，选择“退出”。程序同时保留一个实例；再次启动时继续使用已有实例。

调整图片比例、角色映射或制作本地 EXE 时，按[开发指南](开发指南.md)完成对应流程。

## 表情、动作与移动

将鼠标移到日常状态的角色上，糖猫会换成悬停表情；移开后恢复。停留期间，下一次自动活动的等待也会暂停。

单击播放一个随机普通动作，并显示气泡短句；双击从 GIF 动作中选择。单击会等待 Windows 的双击判定时间，因此反应有一小段延迟。点击可以切换正在播放的普通动作，也可以接管自主移动。

右键选择“随机动作”可以直接换动作；选择“出去走走”会开始一次迈步、跳跳或跑动。移动结束后，糖猫留在当前位置。

按住角色缓慢拖动，松手后放在新位置。拖动中会显示倒立形象，放下后回到日常。拖到另一块显示器后，后续自动移动就在那块屏幕内进行。

快速拖动并松手会触发投掷：糖猫沿释放方向飞行，碰到屏幕边缘反弹，逐渐减速，最后显示落地表情。飞行期间可以从托盘藏起或退出；落地表情还可通过右键行为命令切换。

## 和鼠标玩耍

1. 右键角色，选择“和糖猫玩耍”，开始一轮 90 秒的互动。
2. 将鼠标移远，观察糖猫靠近；在附近慢慢移动，观察伸手或打招呼。
3. 围绕角色画圈，观察疑惑表情；等待一段时间，还会出现追逐。
4. 提前结束时，右键选择“停止玩耍”。

玩耍由鼠标位置驱动，单击和双击维持当前会话。缓慢拖放后继续玩耍，快速甩出则转入投掷。已经开始的会话会在暂停活动或鼠标穿透期间继续计时；进入全屏应用会结束这一轮玩耍。

## 调整陪伴方式

右键角色可以控制动作、移动、玩耍、暂停、大小、藏起和退出。托盘额外提供环境感知、鼠标穿透、性格，以及藏起后的叫回入口。

| 设置 | 操作与效果 |
|---|---|
| 性格 | 在托盘的“性格”中选择安静、默认或活泼。安静的等待较长、移动较少；活泼的活动更频繁。切换时当前动作继续，日常等待按新性格重新开始。 |
| 环境感知 | 在托盘中勾选或取消“环境感知”。开启后，本地时间和系统空闲时长影响自动活动的偏好：夜间或空闲时偏向睡觉，操作活跃时偏向工作。 |
| 暂停活动 | 右键角色或托盘，选择“暂停活动”。当前动作、移动或玩耍继续，之后停在日常；点击互动仍可使用。选择“继续活动”恢复日常的剩余等待。 |
| 鼠标穿透 | 在托盘中勾选“鼠标穿透”，鼠标操作穿过角色，自动活动继续。恢复互动时从托盘取消勾选。 |
| 调整大小 | 右键角色或托盘，在“调整大小”中选择 `75%`、`100%`、`125%` 或 `150%`。角色会保持在当前屏幕可用区域内。 |
| 藏起与叫回 | 选择“藏起来”结束当前行为并隐藏角色。从托盘选择“叫糖猫回来”，它会出现在最后所在显示器右下角，开始新的日常；该屏幕断开后使用主显示器。 |

叫回会沿用本次大小、穿透和暂停设置。完全退出再启动时，只保留性格和环境感知；大小恢复为 `100%`，暂停和穿透关闭，位置回到主显示器右下角。

普通桌面中糖猫置顶。同一显示器出现全屏应用、游戏或视频时，它自动隐藏；退出全屏后，普通动作、移动和投掷继续原来的进度。其他显示器的全屏内容保持糖猫所在屏幕的状态。玩耍和正在进行的拖拽在全屏结束后回到新的日常。

## 处理运行问题

| 现象 | 处理方法 |
|---|---|
| 提示缺少 `PIL` | 在当前 PowerShell 中执行 `python -m pip install -r requirements.txt`，为 npm 脚本使用的 Python 安装 Pillow。 |
| 提示“缺少素材”或“素材内容重复” | 按报错 ID 核对文件名、格式和内容。共享图片通过清单引用同一个 ID，修正后重新启动。 |
| 糖猫消失，托盘显示“叫糖猫回来” | 点击该项，角色回到屏幕右下角。 |
| 全屏后糖猫消失 | 退出糖猫所在显示器的全屏模式，等待监测确认后恢复。 |
| 角色仍在活动，但鼠标点不到 | 从托盘取消“鼠标穿透”。 |
| 角色停在日常表情 | 移开鼠标；托盘显示“继续活动”时，点击该项恢复等待。 |
| 再次启动后没有变化 | 使用现有托盘管理已启动的实例。 |
