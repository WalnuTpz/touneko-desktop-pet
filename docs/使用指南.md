# 使用糖猫桌宠

糖猫会在桌面上随机切换日常表情、播放动作和散步，也会回应你的鼠标互动。使用者先准备源码与表情包，在本机启动；需要 EXE 时再进行本地打包。本文介绍首次运行、互动和设置。

## 首次运行

在 Windows 10/11 x64 上安装 Node.js 22.12.0 或更高版本、Python 3.10 或更高版本。获取仓库源码，在包含 `package.json` 的根目录打开 PowerShell，安装依赖：

```powershell
python -m pip install -r requirements.txt
npm ci
```

打开 `assets/catalog.json`，按其中的 ID 准备本地表情包：

1. 创建 `assets/local/static/`，为 `staticAssets` 中每个 ID 放入一张同名 PNG，例如 `stand.png`。
2. 创建 `assets/local/animated/`，为 `animatedAssets` 中每个 ID 放入一份同名 GIF，例如 `movement-jump.gif`。
3. 按当前清单补齐 136 张 PNG 和 21 份 GIF，图片内容匹配其日常、动作或移动用途。使用透明背景，让角色轮廓参与鼠标命中与碰撞。
4. 在项目根目录运行：

```powershell
npm start
```

启动命令先检查清单并生成运行时素材，再打开 Electron。糖猫会出现在主显示器可用区域的右下角，并显示一次随机开场白；任务栏通知区域同时出现糖猫图标。图标被收起时，展开通知区域查看。角色映射、素材尺寸和替换后的验证方法见[素材说明](../assets/README.md)。

## 再次启动和退出

平时在项目根目录执行 `npm start`。更换本地图片后，同一命令会重建素材。结束使用时，右键糖猫或托盘图标，选择“退出”。

需要双击启动的程序时，完成素材调整并退出桌宠，执行 `npm run dist`。构建通过后，双击 `release/` 中生成的便携版 EXE；成品已经包含本次素材与运行环境。完整检查、构建和成品核验步骤见[本地构建](本地构建.md)。

程序由用户手动启动，同一时间运行一个实例。重复启动会保留已有实例的状态，藏起的糖猫从托盘叫回。

## 和糖猫互动

### 表情与动作

将鼠标移到角色可见部分，日常表情会变为对应的悬停表情；移开后恢复原来的日常表情。悬停期间，下一次自动活动的倒计时暂停。

单击播放一个随机普通动作，可能是静态表情，也可能是 GIF。程序会等待 Windows 的双击判定时间，再确认单击。双击直接从 GIF 动作中选择一个。新的有效点击会接管正在播放的普通动作或移动，动作结束后开始新一轮日常活动。

右键糖猫选择“随机动作”也能播放普通动作；选择“出去走走”会开始一次迈步、跳跳或跑动。移动结束后，糖猫停在当前位置。

### 移动位置和投掷

按住角色，缓慢拖到目标位置后松手。拖动中糖猫显示倒立形象，放下后切换到新的日常表情。可以拖到另一块显示器，后续自动活动就在那块显示器内进行。

快速拖动并松手会把糖猫甩出去。它沿释放方向飞行，碰到屏幕边缘反弹，逐渐减速，最后显示一个落地表情。飞行期间等待它落地；落地表情可以通过右键“随机动作”或“出去走走”切换。托盘的“藏起来”和“退出”在这些阶段都可用。

### 鼠标玩耍

1. 右键糖猫，选择“和糖猫玩耍”。每轮持续 90 秒。
2. 将鼠标移远，糖猫会向鼠标靠近。
3. 在角色附近缓慢移动鼠标，观察伸手或打招呼。
4. 围绕角色画圈，观察疑惑表情；停留一段时间还会出现追逐。
5. 提前结束时，右键糖猫，选择“停止玩耍”。

玩耍期间，鼠标位置驱动反应，单击和双击保持当前玩耍状态。仍可缓慢拖动糖猫后继续玩耍；快速甩出会转入投掷。手动暂停活动后，已经开始的玩耍仍按 90 秒结束。进入全屏应用会结束这一轮玩耍，退出全屏后回到日常。

## 调整日常活动

### 性格和环境感知

右键托盘图标，打开“性格”并选择一项：

| 性格 | 两次自动行为之间的日常等待 | 自动活动倾向 |
|---|---|---|
| 安静 | 35～50 秒 | 普通动作较多，移动较少 |
| 默认 | 20～30 秒 | 普通动作与移动交替 |
| 活泼 | 10～18 秒 | 活动更频繁，移动比例更高 |

切换性格会保留正在进行的行为；在日常或悬停状态切换时，按新性格重新计时。

托盘中的“环境感知”默认开启。夜间或电脑空闲较久时，糖猫更偏向睡觉；操作活跃时更偏向工作。它使用本地时间与系统空闲时长，手动点击和菜单抽取保持原来的规则。再次点击“环境感知”可取消勾选。

### 暂停、穿透和藏起

这三种操作控制不同的事情：

| 操作 | 操作步骤 | 操作后的状态 | 恢复方法 |
|---|---|---|---|
| 暂停活动 | 右键角色或托盘，选择“暂停活动” | 当前动作或移动完成后停留在日常；手动互动继续可用 | 在相同菜单选择“继续活动” |
| 鼠标穿透 | 右键托盘，勾选“鼠标穿透” | 鼠标可以操作角色下方的窗口，自动活动继续 | 右键托盘，取消勾选“鼠标穿透” |
| 藏起来 | 右键角色或托盘，选择“藏起来” | 当前行为结束，角色隐藏，托盘保留 | 右键托盘，选择“叫糖猫回来” |

叫回后，糖猫出现在本次运行最后所在显示器的右下角，开始新的日常状态。该显示器已断开时使用主显示器。大小、穿透和暂停设置沿用本次运行的选择。

### 大小与全屏应用

右键角色或托盘，打开“调整大小”，选择 `75%`、`100%`、`125%` 或 `150%`。调整后，程序会将可见角色保持在当前显示器可用区域内。

糖猫在普通桌面上置顶。当前显示器出现全屏应用、游戏或视频时，它会自动隐藏；退出全屏后，普通动作、移动和投掷接着原进度继续。其他显示器的全屏应用不影响糖猫。玩耍和正在进行的拖拽在全屏切换后转入新日常。

## 下次启动保留哪些设置

性格和环境感知保存在本机，下次启动继续使用。每次完全退出后重新打开，大小恢复为 `100%`，暂停和鼠标穿透关闭，位置回到主显示器右下角，方向、最近动作记录和行为进度重新开始。

## 找回看不见或点不到的糖猫

- **糖猫消失，托盘显示“叫糖猫回来”**：点击该项，糖猫会回到显示器右下角。
- **糖猫在全屏应用打开后消失**：退出当前显示器的全屏模式，等待监测确认后恢复。
- **角色仍在活动，但鼠标点不到**：从托盘取消勾选“鼠标穿透”。
- **角色停在日常表情**：先移开鼠标，再查看托盘是否显示“继续活动”；选择后从剩余等待时间继续。
- **重复启动后没有变化**：使用现有托盘图标管理已启动的糖猫。
