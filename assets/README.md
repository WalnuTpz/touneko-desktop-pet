# 素材目录

```text
assets/
├─ README.md
├─ local/
│  ├─ 糖猫合集/
│  └─ 日常与悬停拖拽/
└─ generated/
   ├─ manifest.json
   ├─ files/
   │  ├─ static/
   │  └─ animated/
   └─ icons/
```

## `local/`

- 保存用户本地的原始 PNG 和 GIF。
- 程序和脚本只读取这些文件，不修改、覆盖或删除它们。
- `日常与悬停拖拽/` 使用奇数日常、偶数悬停的编号配对规则；无编号的 `倒立.png` 是拖拽专用素材。
- `日常与悬停拖拽/` 中的所有素材都禁止进入普通动作池；如果合集里存在相同内容，也会按内容哈希排除。
- `糖猫合集/` 用于建立普通动作池和四种移动素材。

## `generated/`

- 由 `python scripts/prepare_assets.py --check` 自动重建。
- 保存运行时实际使用的静态副本、现有 GIF 的逐帧副本、碰撞边界、帧时长、素材池清单和多 DPI 图标。
- GIF 逐帧副本只用于忠实播放原 GIF、暂停恢复和逐帧碰撞，不会把静态图片合成为新动画。
- 大部分素材使用自动视觉尺寸；少量明显过大或过小的素材使用 `scripts/asset-overrides.json` 中的人工倍率。带问号、吊瓶、长手或大型道具的素材按糖猫本体而不是画面总高度判断。
- 自动统一与人工倍率完成后，再对全部桌宠图片应用 `80%` 的全局显示倍率；该倍率不影响气泡字号或系统托盘图标。
- 不要在此目录手动保存文件；重新准备素材时目录会被整体替换。

`local/`、`generated/` 和生成过程的暂存目录均被 Git 忽略，不会上传到代码仓库。
